# CmsPro-朋友圈博客-使用指南

> 应用标识：`niuren.blog` ｜ 版本：1.3.0 ｜ 更新日期：2026-08-24

## 一、应用概述

朋友圈博客是一款模仿微信朋友圈风格的轻博客应用：

- **前台**：卡片式动态流展示，支持发布纯文字、图文动态（图片九宫格，最多九张）
- **后台**：文章管理（列表筛选、图文发布与编辑、删除、草稿/发布状态管理）；博客设置（基础设置 + 访问设置）

适用场景：个人站点动态、团队内部分享墙、轻量内容发布。

## 二、安装与卸载

### 安装

1. 进入后台「应用市场 / 应用管理」，找到「朋友圈博客」点击安装
2. 安装流程自动完成：
   - 创建数据表 `app_niuren_blog_posts`
   - 写入后台菜单（朋友圈博客 → 文章管理、博客设置）
   - 写入配置项（博客设置：每页文章数、访问设置三项，见「配置说明」）
   - 发布静态资源 `Assets/` → `public/apps/niuren.blog/`

### 卸载

后台应用管理中卸载将自动回滚数据表、移除菜单、清理已发布静态资源与缓存。**卸载会删除全部文章数据，请先备份。**

### 升级

应用包版本提升后（如 1.0.0 → 1.0.1），在应用管理中执行升级，自动执行新增迁移并刷新静态资源。

## 三、功能说明

### 3.1 后台文章管理

入口：后台菜单「朋友圈博客 → 文章管理」（`/admin/niuren/blog/posts`）

| 操作 | 步骤 |
|------|------|
| 浏览 | 列表页支持内容关键词搜索、状态（已发布/草稿）筛选、分页 |
| 写文章 | 点击「写文章」→ 填写正文、上传图片（可选，最多九张，单张 ≤5MB）、选择状态（草稿/发布）→ 保存；正文与图片至少填一项 |
| 编辑 | 列表行「编辑」→ 修改后保存 |
| 删除 | 列表行「删除」→ 确认后删除（不可恢复） |

### 3.2 前台动态流

| 页面 | 地址 | 说明 |
|------|------|------|
| 动态流 | `/blog` | 朋友圈卡片流，仅显示已发布动态，按时间倒序 |
| 写动态 | `/blog/write` | 填写正文或上传图片（至少一项，图片最多九张）后发布，发布即为已发布状态 |
| 动态详情 | `/blog/{id}` | 单条动态完整内容与图片 |

前台 UI 自 v1.3.0 起对齐微信朋友圈视觉与交互：

- **顶部导航栏**：固定悬浮 44px，标题「朋友圈」，左侧返回箭头，右侧相机（进入写动态）与深浅色切换按钮；列表页滚动时背景由透明渐变为浅灰
- **封面头部区**：页面顶部 1/3 高度的封面区，右侧悬浮昵称与 75px 大头像；下拉页面封面随滚动放大产生视差效果（当前为内置渐变占位封面）
- **动态卡片**：左 42px 头像 + 右内容区左右分栏，昵称为蓝色可点击，正文完整展示不折叠
- **媒体九宫格**：图片按数量自适应布局（单图保持原比例最大宽 70%、2/4 张两列、3/5-9 张三列网格），单图超长自动在底部裁切并标注「长图」；点击图片进入全屏浏览，支持左右切换（或键盘方向键）、双击/点击放大、Esc 关闭
- **点赞评论气泡**：灰底圆角气泡，点赞行 + 评论列表（有赞有评论时以分隔线隔开）；`评论` 按钮或点击气泡空白唤起底部输入条，发表后自动追加并刷新计数
- **时间展示**：发布相对时间（刚刚 / N 分钟前 / 今天 HH:mm / 昨天 / MM-DD）
- **深色模式**：顶部月亮/太阳按钮或跟随系统切换，采用纯黑背景 + 深灰卡片色系

### 3.3 前台写动态页

| 元素 | 说明 |
|------|------|
| 顶部导航 | 左侧返回（取消），右侧「发表」按钮（有正文或图片才可点击） |
| 正文编辑区 | 顶部对齐多行输入，占位「这一刻的想法...」，上限 2000 字，实时字数统计 |
| 图片预览区 | 正方形圆角缩略图 + 右上角删除按钮，末尾「+」追加选择，最多 9 张，逐张上传至公共上传接口 |
| 发布 | 正文与图片至少一项，发布成功跳回动态流 |

## 四、配置说明

后台菜单「朋友圈博客 → 博客设置」（`/admin/niuren/blog/setting`）以 Tab 页签组织：

### 基础设置

| 配置项 | code | 默认值 | 说明 |
|--------|------|--------|------|
| 每页文章数 | `app_niuren_blog_posts_per_page` | 10 | 前台动态流每页条数，范围 1-100 |

### 访问设置（三选一）

| 配置项 | code | 类型 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 访问方式 | `app_niuren_blog_access_mode` | select | root | 博客对外提供访问的方式：根路径（/）、路径前缀（如 /blog）、子域名绑定（如 blog.example.com），三选一 |
| 路径前缀 | `app_niuren_blog_access_path_prefix` | text | /blog | 访问方式为「路径前缀」时生效，以 `/{前缀}` 形式访问博客（如 `/blog`） |
| 绑定子域名 | `app_niuren_blog_access_domain` | text | （空） | 访问方式为「子域名绑定」时生效，填写独立域名/子域名（如 `blog.example.com`） |

保存后即时生效。注：当前版本仅落地访问配置的存储与管理界面，前台按所选方式的多入口路由分发将在后续版本实现。

## 五、依赖关系

- PHP >= 8.1，CMSPRO >= 5.0.0
- 无其他应用依赖

## 六、注意事项

1. **前台发布无需登录**：当前版本前台发布接口未强制登录校验，如需登录后发布，可在 `Routes/web.php` 的 `publish` 路由追加 `auth` 中间件
2. **图片字段**：数据表 `images` JSON 字段存储图片 URL 列表；前台 `/blog/write` 与后台「写文章」均已内置九宫格上传控件（单张 ≤5MB，最多九张），也可通过 API 直接传入 `images` 数组
3. **草稿不外显**：前台列表与详情仅展示 `status=1` 的已发布动态
4. **静态资源 404 排查**：若前台样式丢失，确认 `public/apps/niuren.blog/` 目录存在；缺失时在后台执行应用升级重新发布
5. **日期格式**：数据库统一存储 `Y-m-d H:i:s`；前台动态卡片通过 `data-time` 交由前端 JS 转换相对时间展示（刚刚 / 今天 HH:mm / 昨天 / MM-DD 等），参见 `Assets/js/app.js` 的 `formatTime`
6. **前台写动态**：`/blog/write` 为纯前端表单，拖动选择图片后逐张调用公共上传接口 `/blog/upload`（单张 ≤5MB、最多 9 张），提交 `/blog/publish` 发布；正文与图片至少填一项，否则「发表」按钮置灰
7. **深浅色模式**：前台样式基于 CSS 变量，顶部月亮/太阳按钮切换并在 `localStorage` 记忆，未设置时跟随系统 `prefers-color-scheme`
8. **静态资源发布**：前台样式/脚本改动后需将 `Assets/css/style.css`、`Assets/js/app.js` 同步复制到 `public/apps/niuren.blog/`（安装/升级时系统自动发布，开发环境可手动复制）

## 七、常见问题

**Q：编辑页和新建页是同一个页面吗？**
是。`Admin/Post/create.blade.php` 根据是否传入 `$post` 自动切换标题与提交地址（POST 新建 / PUT 更新）。

**Q：后台表格显示"暂无数据"？**
检查接口 `/api/admin/niuren/blog/posts/list` 响应。列表数据映射依赖视图内 `parseData` 配置（`data.list` → 表格行、`data.total` → 总数）。

**Q：如何调整前台每页显示条数？**
后台菜单「朋友圈博客 → 博客设置 → 基础设置」中修改保存即可。

**Q：根路径、路径、子域名三种访问方式如何切换？**
在「博客设置 → 访问设置」的「访问方式」下拉中三选一即可；选择「路径前缀」或「子域名绑定」时需同步填写对应的前缀/域名，否则保存时会提示必填校验错误。
